What is different from the reference

The reference plays a pre-rendered 11 s MP4 with the layer names baked in, paused, with currentTime driven by scroll — there is no WebGL on that page at all. Everything here is drawn live, so the labels come from a data array and stay editable. The gap you will see is in the glass: offline rendering gets caustics and multi-bounce refraction that a real-time transmission pass cannot.
